# 运行说明

这份仓库是静态页面，无需构建工具即可查看。以复古播放器页面为例，任选下列方式访问：

## 方式一：直接双击文件
1. 克隆或下载本仓库。
2. 在文件管理器中双击 `retro-player.html`，浏览器会直接打开页面并可播放内置示例曲目。

## 方式二：启动本地静态服务器
1. 在仓库根目录执行：
   ```bash
   python3 -m http.server 8000
   ```
2. 打开浏览器访问 <http://localhost:8000/retro-player.html>。

> 如需放到线上，只要把仓库文件放进任意支持静态文件托管的服务（例如 Nginx、GitHub Pages 等）即可。
